# kiros-weg

**Kiros Weg (طريق كيرو):** تطبيق موبايل فيه خطة الألماني من A1 لـB1. فيه مهام كل يوم، وكل الروابط، والمواعيد، والكلمات، والمتابعة. والخلفية لوحة بتتحرك ببطء: بحر إسكندرية أو جبال وضباب، وألوانها بتتغير مع الفجر والنهار والمغرب والليل.

- **التطبيق:** https://king4664.github.io/kiros-weg/
- **مصدر الحقيقة:** [`german-plan.md`](german-plan.md). أي تاريخ أو رابط أو رقم أو كلمة في التطبيق جاي منه.
- **المواصفات كاملة:** [`SPEC.md`](SPEC.md). والقواعد المختصرة في [`CLAUDE.md`](CLAUDE.md).

## على الموبايل

1. افتح اللينك من Chrome أو Brave على أندرويد.
2. من قايمة المتصفح (⋮) اختار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية». هيظهر باسم «Kiros Weg» بأيقونة الشمس والبحر.
3. بعد أول فتح والنت شغال، التطبيق بيفتح من غير نت. ولما ترفع تحديث جديد، بينزل لوحده أول ما تفتحه والنت شغال.

**بياناتك على الموبايل بس.** المتابعة، والجمل، والإعدادات، كلها في `localStorage` (تخزين جوه المتصفح). مفيش سيرفر ولا حساب. فاعمل نسخة كل أسبوع من **المتابعة** أو **الإعدادات ← النسخ الاحتياطي ← Export**، واحتفظ بالملف. ولو غيّرت الموبايل أو مسحت بيانات المتصفح، رجّعها بـ**Import**.

## إزاي تشغّله على الكمبيوتر

محتاج [Node.js](https://nodejs.org) 24.

```bash
npm ci          # يسطّب الحاجات اللي المشروع محتاجها
npm run dev     # يشغّله على http://localhost:5173
npm test        # التستات
npm run build   # يبني النسخة النهائية في dist/
```

**تجرّب الخلفية من اللينك:**
- `?scene=sea` أو `?scene=mountains`
- `&time=dawn` أو `day` أو `sunset` أو `night`، أو ساعة زي `18:30`
- `&motion=off`

مثلًا: `http://localhost:5173/?time=night&scene=sea`

**النشر:** أي push على `main` بيشغّل GitHub Actions (`.github/workflows/deploy.yml`). بيشغّل التستات، وبيبني، وبينشر على GitHub Pages. لو التستات وقعت، مفيش حاجة بتتنشر.

## لما الخطة تتغير

1. حط النسخة الجديدة من الخطة مكان `german-plan.md`.
2. شغّل `npm test`. التستات بتقارن كل البيانات بالخطة، ولو حاجة اتغيرت، التست اللي يقع هيقولك أنهي ملف وأنهي سطر.
3. عدّل الملف ده في `src/data/`، وشغّل `npm test` تاني لحد ما كله ينجح.
4. اعمل commit وpush، والتطبيق هيتحدّث لوحده.

| اللي اتغير في الخطة | الملف |
|---|---|
| الروابط (جزء 18 و26 و29، والنطق في جزء 7) | `src/data/links.json` |
| كلمات الأسبوع 1 و2 (جزء 24 و25) | `src/data/words.json` |
| المواعيد والمحطات (جزء 1) | `src/data/milestones.json` |
| المنهج أسبوع بأسبوع (جزء 6) | `src/data/weeks.json` |
| الساعات (جدول «الحساب» في جزء 3) | `src/data/hours.json` |
| قواعد القرار (جزء 9) | `src/data/decisions.json` |
| قوالب اليوم (جزء 4)، والأسبوع 1 (جزء 7)، واليوم الصغير (جزء 15) | `src/data/templates.json` |
| أيام أول أسبوعين (جزء 7)، وأيام التشخيص والامتحانات التجريبية | `src/data/days.json` |
| أسماء دروس Nicos Weg A1 (من صفحة DW) | `src/data/nicos.json` |

**الأجزاء دي بتتقري من الخطة على طول، فمش محتاجة تعديل:**
- الفرصة (جزء 2)، والأسبوع (جزء 5)، واختبار مارس (جزء 10).
- امتحان B1 (جزء 11)، والكلام مع ناس (جزء 12)، ورسايل Claude (جزء 13).
- شكل رسالة المتابعة وملخص الأسبوع (جزء 14)، ولو اتأخرت (جزء 15).
- الحجوزات والإيميل (جزء 16)، والمخاطر (جزء 19)، ولسه مش متأكدين (جزء 22)، والقاموس (جزء 23).

**مواعيد الفاينل:** لما جدول الكلية ينزل، غيّر `date` و`end` بتوع `finals` في `milestones.json`. ولازم يبقوا نفس تواريخ الأسابيع 7–9 في `weeks.json` ونفس فترة الفاينل في `hours.json`، والتستات بتتأكد من ده. والأسبوع اللي قبل الفاينل بيتحسب لوحده.

## جوه الكود

- `src/lib/`: الحسابات، وكلها عليها تستات:
  - الشمس في إسكندرية، والتواريخ.
  - اليوم في الخطة والسلّم، والمتابعة، والنسخ الاحتياطي.
  - قراية أجزاء الخطة.
- `src/bg/`: اللوحة اللي ورا الشاشات (canvas).
- `src/screens/`: الشاشات: النهارده، والروابط، والخطة، والكلمات، والمتابعة، والإعدادات.
- `src/app/`: الهيكل، والتخزين، والتايمر، والنطق.
- `public/icon.svg`: الأيقونة. صورها بكل المقاسات بتتعمل وقت الـbuild (`pwa-assets.config.ts`).
